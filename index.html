Connect your Supabase project

This app needs a free Supabase project to store accounts and assets. Open index.html in a text editor and fill in the two values near the top of the <script> tag:

  1. Create a free project at supabase.com
  2. Run schema.sql in the Supabase SQL Editor
  3. Copy your Project URL and anon public key from Settings → API
  4. Paste them into SUPABASE_URL and SUPABASE_ANON_KEY
  5. Save and reload this page
